# Oak Park Residential Reassessment

View the app at https://jvanderberg.github.io/op-reassessment/.

This app maps Oak Park single family residential reassessments and compares 2026 market values with 2025 market values. It shows the average increase, median increase, summary tables by neighborhood or property class, and a parcel map colored by percentage increase.

Use the search box to find a property by address or PIN. Use the property class and neighborhood filters to narrow the dataset, then switch the summary table between neighborhood and class views. Click legend ranges on the map to isolate properties by percentage increase without changing the summary totals.

Run `npm run dev` to work locally, `npm run build` to build the site, and `npm run extract` to refresh the local data files.
