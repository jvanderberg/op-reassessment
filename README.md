# Oak Park Residential Reassessment

Static analytical map for Oak Park 2026 residential reassessments.

View the app at https://jvanderberg.github.io/op-reassessment/.

The app is powered by JSON and GeoJSON files generated by repeatable extraction scripts. It does not make live database queries.

Run `npm run extract` to regenerate the datasets, `npm run dev` to work locally, and `npm run build` to build the site.
